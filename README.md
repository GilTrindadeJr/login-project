# Login Project

Tela de login com tema escuro, validação de campos via JavaScript.

## Funcionalidades
- Validação de campos obrigatórios
- Autenticação simulada (usuário: adm / senha: 123)
- Mensagens de feedback ao usuário
- Dashboard pós-login
- Tela de cadastro de usuários

## Tecnologias
- HTML5, CSS3, JavaScript

## Como usar
Abra o arquivo `index.html` no navegador.
